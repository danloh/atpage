Here to share the styles and scripts of your atpage 

# How to share?

Just put your style `.css` file in the folder: `/shared/styles` and script `.js` file in the folder `shared/scripts` and attach your atpage link to check the output. 

# How to use? 

1. check the file and modify as you want;
2. copy and paste the content to `Scripts` or `Styles` input box on `/setup` page;
3. check the output on your atpage; 
4. repeat the steps 1-3 as you want.
